# ***Proyecto Final: Talleres Artísticos***

Este proyecto consiste en el desarrollo de una pequeña aplicación que permita registrar la participación de personas
en talleres artísticos: pintura, teatro o danza y genera reportes con pandas y matplotlib.

## Requerimientos técnicos
- tkinter: para crear una interfaz gráfica básica.
- pandas: para organizar y analizar los datos.
- matplotlib: para generar un gráfico sencillo.
- POO: usar al menos una clase.
- GitHub: subir el proyecto con control de versiones.

## Instrucciones
1. Ejecuta "interfaz.py" para abrir la interfaz.
2. Registra información de participantes: nombre, edad, taller inscripto y clases tomadas.
3. Visualiza reportes con gráficos.

## Estructura
- "participante.py": clase principal.
- "interfaz.py": interfaz gráfica.
- "datos/participantes.csv": archivo con los registros de los participantes.
